CGV 결제 테스트

프론트엔드 대체용 임시 페이지입니다. 토스 테스트 키로만 사용하세요.

0. 토스 클라이언트 키

.env 의 TOSS_CLIENT_KEY 값입니다. 이 페이지는 결제위젯 SDK를 사용하므로 test_gck_ 로 시작하는 키가 필요합니다. (test_ck_ 는 일반결제용이라 동작하지 않습니다.) 브라우저에 노출되는 값이라 공개되어도 무방하며, localStorage에 보관됩니다.

1. 로그인

2. 결제 요청 정보 사전 등록 (/payments/ready)







    
3. 결제위젯

    
2번을 먼저 실행하면 위젯이 렌더링됩니다.

    

    

    
    

        결제를 마치면 서버의 /api/v1/payments/toss/success 로 리다이렉트되고,
        그 응답(JSON)이 브라우저에 그대로 표시됩니다.
